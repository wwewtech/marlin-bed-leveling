UBL Workflow Phases

G29 P0 / P1

Initialize and auto-probe. Zero the mesh (P0) to prepare a clean slate, then run the automated probing (P1) to build the baseline topology.

G29 P3 / P4

Smart-fill unreachable points (P3) that the probe can't access. Fine-tune specific bad regions manually (P4 T) for the perfect first layer.

M421 / G26

Edit mesh points directly with M421 (crucial for LCD-less setups). Run G26 C P to print a validation pattern and identify areas needing adjustment.
